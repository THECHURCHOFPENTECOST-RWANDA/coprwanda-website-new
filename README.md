# COPIRWA Website Starter

A responsive static website starter for The Church of Pentecost International Rwanda.

## Included
- Homepage and core pages from the Church Website Structure and Content Plan
- Shared responsive navigation, header and footer
- Mobile navigation toggle
- Basic page-name search
- Cookie notice
- 404 page and site directory
- CSS and JavaScript separated into `css/` and `js/`

## Important before public launch
This starter intentionally does not invent official church details. Replace content marked for confirmation with information approved by the national office:
- official logo and brand guide
- leadership names, titles, biographies and approved photographs
- church history, vision, mission and beliefs
- service schedules, assembly locations and ministry contacts
- official email, telephone, address and social links
- verified giving instructions
- approved event, sermon and livestream links
- privacy policy and terms of use

The current `COP` mark is a temporary text mark, not an official logo. Replace it with an approved logo file and update the header/footer as needed.

Forms, online payments, secure prayer submissions, newsletter subscriptions, live video embeds, multilingual translated pages, and an interactive map require verified services/content and are not connected in this static starter. Do not collect sensitive submissions until an approved secure process is implemented.

## Test locally
Open `index.html` in a browser. Navigation links point to files in this folder.

## Publish with GitHub Pages
Upload the contents of this folder to the root of a GitHub repository. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)` folder. Wait for GitHub Pages to publish, then test the published URL.
